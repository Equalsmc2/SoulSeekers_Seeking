R02 MULTIPLAYER MIGRATION

No Firebase setup changes are needed.

Firebase Realtime Database is no longer used for shooter position updates or host/client room state.
R02 uses a separate Node/WebSocket dedicated server on Render (or your own machine) and keeps the Firebase configuration file untouched for later accounts features.

READ: R02_SERVER_SETUP.md

1. Push R02 to GitHub using SYNC_TO_GITHUB.bat.
2. On Render create a new Web Service from your GitHub repo.
3. Build: npm install --omit=dev | Start: npm start
4. Open the Render service URL in your browser.
5. Host a DM room and Copy Invite Link for players.

No need to delete your Firebase project or relax database rules.
