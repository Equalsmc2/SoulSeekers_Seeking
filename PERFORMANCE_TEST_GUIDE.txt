R01.7 multiplayer test
1. Unzip, run SYNC_TO_GITHUB.bat, commit and push from GitHub Desktop.
2. Hard reload both browsers (Ctrl + Shift + R) and host a NEW room.
3. Keep DM and Party in two VISIBLE browser windows side-by-side (not two hidden tabs).
4. Move the Party character with WASD. Local movement should be immediate.
5. Check the DM window shows Party movement after a short delay.
6. Aim and fire. Hits/health are still authoritative and can lag with network round trips.
7. Check the Party HUD says FIREBASE / <...>ms SNAPSHOT AGE. If it repeatedly says SYNC DELAYED, the DM or network is throttled.
8. For comparison, also test separate computers/devices.
Known limitation: a hidden DM browser cannot guarantee real-time simulation with Firebase as the only backend.
