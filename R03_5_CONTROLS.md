# R03.5 — In-game UI controls

| Key | Result |
|---|---|
| I | Open/close inventory (Party) |
| B | Open/close jungle market (Party) |
| L | Open/close combat feed (all) |
| F3 | Toggle network & frame-time stats (all) |
| Esc | Close any open panel and cancel placement / release possession |

Only one of Inventory / Shop / Feed is open at a time. Clicking a toolbar button a second time closes that drawer. Shopping is still only possible near a shop and with sufficient gold. The DM retains all three enemy buttons and the lane selector.

The active version number appears beside FIELD OPERATIONS in the top-left header.
